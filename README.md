# 천산중앙교회 장례문자 (웹앱)

휴대폰에서 부고 문구를 만들고, 교인 명단에 한 번에 보내기 위한 웹앱입니다.

- 배포 주소: https://cheonsan1.github.io/cheonsan-funeral-sms/
- 저장소에는 웹 화면(`index.html`) 한 파일만 들어 있습니다. 서버 코드·설정·개인정보는 포함되지 않습니다.

## 지금 바로 되는 것 (서버 없이)

- 부고 정보 입력 → 미리보기 (교회 양식 그대로: `故 … 소천(…)` / `▶장례식장:` / `▶위로예배:` / `▶맺음말`)
- 받은 카톡 부고를 붙여넣고 **자동 채우기**
- EUC-KR 기준 바이트 수(SMS 90B / LMS 2,000B)와 인원별 예상 비용 계산
- **문구 복사** → 카톡·문자에 붙여넣기
- 교인 명단 CSV 업로드(이름, 직분, 구역, 전화번호 / UTF-8·EUC-KR), 검색·구역/직분 필터, 전체 선택, 테스트 수신자

## 개인정보

- 교인 명단은 코드에 넣지 않았습니다. 명단을 올리면 **그 기기의 브라우저(localStorage)에만** 저장되고 어디로도 전송되지 않습니다.
- 공용 기기에서는 사용 후 ‘명단’ 탭의 **명단 비우기** 또는 ‘기록·설정’의 **이 기기의 데이터 모두 지우기**를 눌러 주세요.

## 실제 발송

비즈뿌리오 API는 등록된 고정 IP에서만 호출되므로, 고정 IP가 있는 중계서버가 필요합니다.
웹앱 ‘기록·설정’ 탭에서 중계서버 주소를 넣고 교역자 계정으로 로그인하면 앱에서 바로 발송할 수 있습니다.

## 휴대폰에 앱처럼 추가

- 아이폰 Safari: 공유 → **홈 화면에 추가**
- 안드로이드 Chrome: 메뉴 → **홈 화면에 추가**
